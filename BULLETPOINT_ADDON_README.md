# Bulletpoint Cheatsheet Generation and Enhanced Benchmarking

This repository contains enhanced tools for dynamic cheatsheet generation and comprehensive benchmarking with detailed logging capabilities.

## 🔧 Main Components

### 1. Enhanced Cheatsheet Generation with Bulletpoint Approach
**File**: `generate_cheatsheet_with_reflection_add_bulletpoint.py`

This script generates dynamic cheatsheets using a bulletpoint-based delta approach with comprehensive LLM call logging.

### 2. Enhanced Benchmark Tool with Multiple Approaches
**File**: `run_benchmark_finlora_fixed.py`

An enhanced benchmarking tool that supports multiple evaluation approaches including baseline, fixed cheatsheet, and detailed logging.

## 📊 Key Features

### Cheatsheet Generation Features:
- **Delta Bulletpoint Approach**: Incremental cheatsheet updates using structured delta additions
- **Multi-Model Support**: Separate models for generation, reflection, and curation
- **Comprehensive Logging**: Detailed timing and content logging for all LLM calls
- **Real-time Evaluation**: Continuous accuracy tracking during training

### Benchmark Features:
- **Multiple Approaches**: `no_cheatsheet`, `fixed_cheatsheet`, `test_with_global_cheatsheet`
- **Detailed Logging**: Optional comprehensive logging of all prompts and responses
- **Flexible Configuration**: Support for different models, sampling ratios, and evaluation modes

## 🚀 Usage Instructions

### 1. Generate Dynamic Cheatsheets with Bulletpoint Approach

#### Basic Usage (Small Test):
```bash
python generate_cheatsheet_with_reflection_add_bulletpoint.py \
    --dataset_path data/finlora/train/finer_train_batched.jsonl \
    --test_dataset_path data/finlora/test/finer_test_batched.jsonl \
    --save_path ./test_cheatsheet_generation \
    --num_samples 3 \
    --num_test_samples 3 \
    --num_epochs 1 \
    --curator_model "Llama-4-Maverick-17B-128E-Instruct" \
    --reflector_model "Llama-4-Maverick-17B-128E-Instruct" \
    --generator_model "Meta-Llama-3.1-8B-Instruct" \
    --max_num_rounds 3
```

#### Full Production Run:
```bash
python generate_cheatsheet_with_reflection_add_bulletpoint.py \
    --dataset_path data/finlora/train/finer_train_batched.jsonl \
    --test_dataset_path data/finlora/test/finer_test_batched.jsonl \
    --save_path ./8b_m_m_bulletpoint_multi_epoch_sambanova \
    --num_samples 500 \
    --num_test_samples 10 \
    --num_epochs 1 \
    --curator_model "Llama-4-Maverick-17B-128E-Instruct" \
    --reflector_model "Llama-4-Maverick-17B-128E-Instruct" \
    --generator_model "Meta-Llama-3.1-8B-Instruct" \
    --max_num_rounds 3
```

#### Parameters:
- `--num_samples`: Number of training samples to use (-1 for all)
- `--num_test_samples`: Number of test samples for evaluation
- `--num_epochs`: Number of training epochs
- `--max_num_rounds`: Maximum reflection rounds per failed question
- `--curator_model`: Model for cheatsheet curation
- `--reflector_model`: Model for error reflection
- `--generator_model`: Model for answer generation

#### Output:
The script creates a timestamped directory containing:
- `final_cheatsheet.txt`: The generated cheatsheet
- `epoch_results.json`: Training progress and metrics
- `training_summary.json`: Complete training summary
- `detailed_llm_logs/`: Comprehensive logs of all LLM calls
- `run_config.json`: Run configuration for reproducibility

### 2. Enhanced Benchmarking with Multiple Approaches

#### No Cheatsheet Baseline:
```bash
python run_benchmark_finlora_fixed.py \
    --dataset "xbrl_finer" \
    --approach_name "no_cheatsheet" \
    --model_name "DeepSeek-V3-0324" \
    --save_directory "baseline_results" \
    --sample_ratio 0.01 \
    --detailed_log
```

#### Fixed Cheatsheet Evaluation:
```bash
python run_benchmark_finlora_fixed.py \
    --dataset "xbrl_finer" \
    --approach_name "fixed_cheatsheet" \
    --fixed_cheatsheet_path "path/to/your/cheatsheet.txt" \
    --model_name "DeepSeek-V3-0324" \
    --save_directory "fixed_cheatsheet_results" \
    --sample_ratio 0.01 \
    --detailed_log
```

#### Global Dynamic Cheatsheet:
```bash
python run_benchmark_finlora_fixed.py \
    --dataset "xbrl_finer" \
    --approach_name "test_with_global_cheatsheet" \
    --cheatsheet_prompt_path "path/to/cheatsheet/directory/" \
    --model_name "DeepSeek-V3-0324" \
    --save_directory "dynamic_cheatsheet_results" \
    --sample_ratio 0.01 \
    --detailed_log
```

#### Using Generated Cheatsheets:
```bash
# Use a cheatsheet generated by the bulletpoint approach
python run_benchmark_finlora_fixed.py \
    --dataset "xbrl_finer" \
    --approach_name "fixed_cheatsheet" \
    --fixed_cheatsheet_path "8b_m_m_bulletpoint_multi_epoch_sambanova/run_[timestamp]/final_cheatsheet.txt" \
    --model_name "DeepSeek-V3-0324" \
    --save_directory "generated_cheatsheet_results" \
    --sample_ratio 0.01 \
    --detailed_log
```

#### Parameters:
- `--approach_name`: Choose from `no_cheatsheet`, `fixed_cheatsheet`, `test_with_global_cheatsheet`
- `--detailed_log`: Enable comprehensive logging of all prompts and responses
- `--sample_ratio`: Fraction of dataset to use (0.001 = 0.1%, 0.01 = 1%, 1.0 = 100%)
- `--fixed_cheatsheet_path`: Path to fixed cheatsheet file (for fixed_cheatsheet approach)
- `--cheatsheet_prompt_path`: Directory containing multiple cheatsheets (for dynamic approach)

## 📋 Detailed Logging Features

### Cheatsheet Generation Logs:
When running the bulletpoint generation, detailed logs are saved in:
```
save_path/run_[timestamp]/detailed_llm_logs/
├── generator_train_gen_initial_[N]_[timestamp].json
├── reflector_train_reflect_[N]_round_[R]_[timestamp].json
├── generator_train_gen_after_reflect_[N]_round_[R]_[timestamp].json
├── curator_train_curator_[N]_[timestamp].json
└── generator_test_eval_[N]_[timestamp].json
```

### Benchmark Logs:
When using `--detailed_log`, logs are saved in:
```
save_directory/dataset/detailed_logs/model_approach_[timestamp]/
└── question_[NNNN].json  (one file per question)
```

### Log Content:
Each log file contains:
- **Role**: `generator` / `reflector` / `curator`
- **Timing**: `prompt_time`, `response_time`, `total_time`
- **Content**: Complete `prompt` and `response`
- **Metadata**: `model`, `call_id`, `timestamp`, text lengths
- **Performance**: Accuracy flags and comparison with ground truth

## 🔄 Workflow Example

1. **Generate Cheatsheet**:
   ```bash
   python generate_cheatsheet_with_reflection_add_bulletpoint.py [params]
   ```

2. **Evaluate Baseline**:
   ```bash
   python run_benchmark_finlora_fixed.py --approach_name "no_cheatsheet" [params]
   ```

3. **Evaluate Generated Cheatsheet**:
   ```bash
   python run_benchmark_finlora_fixed.py --approach_name "fixed_cheatsheet" \
     --fixed_cheatsheet_path "path/to/generated/cheatsheet.txt" [params]
   ```

4. **Compare Results**: Analyze the accuracy improvements and timing logs

This workflow enables systematic evaluation of cheatsheet effectiveness and comprehensive performance analysis.
